Sobre este trabalho

O Abc Bolinhas é um projeto desenvolvido como atividade acadêmica com o objetivo de colocar em prática conhecimentos relacionados ao desenvolvimento web, trabalho em equipe e utilização de ferramentas de controle de versão.

O projeto consiste na criação de um site desenvolvido pelos integrantes da equipe, onde cada membro possui seu próprio espaço para apresentar informações pessoais e profissionais. Cada perfil conta com páginas destinadas à apresentação do integrante, suas habilidades e formas de contato.

Durante o desenvolvimento, foram utilizados conhecimentos de HTML e CSS para a construção e estilização das páginas, além do Git e GitHub para organizar o código, controlar as versões do projeto e permitir o trabalho colaborativo entre os integrantes.

A atividade também proporcionou a experiência de trabalhar com branches, commits, Issues, Pull Requests, merges e atualização do projeto, simulando um fluxo de desenvolvimento utilizado em projetos reais.

O objetivo principal é desenvolver não apenas os conhecimentos técnicos, mas também a capacidade de trabalhar em equipe, organizar um projeto, colaborar com outros desenvolvedores e utilizar ferramentas importantes para o desenvolvimento de software.
